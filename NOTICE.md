### LongMemEval (Wu et al., ICLR 2025)

- **Affected files**:
  - `results/longmemeval/longmemeval_baseline.json`
  - `results/longmemeval/longmemeval_hamib_sbert.json`
  - `experiments/judges/*/judge_input_lme.json`
  - `experiments/judges/*/judge_output_lme.json`
  - `experiments/judges/*/report_lme_*.md`
- **License**: MIT
- **Source**: https://github.com/xiaowu0162/longmemeval
- **Modifications**: items were subset / repackaged into the JSON envelopes used
  by this evaluation harness; the `question` and `gold` field values themselves
  were not edited. The `response` field is our own model output generated by
  running each `question` against an LLM (`baseline`) or against the same LLM
  with HAMIB attention modification applied (`hamib_sbert`).
